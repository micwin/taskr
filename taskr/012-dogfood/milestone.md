# Description

Manage Taskr development practices with Taskr itself.

# Acceptance

- Taskr-specific process and policy work is tracked as dogfood.
- Dogfood tickets use the same worktree format as product tickets.
- Dogfood decisions that affect future agents are reflected in `AGENTS.md` or
  project documentation.

# Comments

- 2026-08-07: Created to keep Taskr process-policy tickets out of the MVP
  product milestone.

# Outcome

Dogfood process and policy work was established as first-class Taskr-managed
work. The milestone captured agent implementation scope, closure checks for
doctor/help/completion/API behavior, and the rule that Taskr dogfood structure
changes use Taskr commands when possible.
