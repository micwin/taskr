# Description

Create a local `.deb` package through the project build script so Taskr can be
installed system-wide on a Debian or Ubuntu workstation before the GitHub
release workflow exists.

# Acceptance

- `scripts/build.sh deb` builds a Debian package without requiring `sudo`.
- `scripts/build.sh all` builds the binary and Debian package.
- `scripts/build.sh deb --install-deb` installs the just-built package as the
  current system `taskr` version.
- The package installs the `taskr` binary under `/usr/bin/taskr`.
- The package version includes the SemVer application version and monotonic
  build metadata generated by the build script, for example `0.1.0+42-1`.
- Build output is written below `dist/`.
- Smokey coverage verifies that the package file is created and contains the
  expected package metadata and binary path.
- Smokey does not execute `--install-deb` because it requires `sudo`.
- The user-facing install command is documented.

# Comments

- 2026-08-07: This is intentionally local packaging first. Publishing artifacts
  through GitHub Releases remains in `008-github-release`.
- 2026-08-07: Debian package creation may use ordinary user-space tooling such
  as `dpkg-deb`; installation can require `sudo`, but package building must not.
- 2026-08-07: The package test should exercise `scripts/build.sh`, not a
  separate `build-deb` script, because versioning is centralized in the build
  script.
- 2026-08-07: Debian package metadata is treated as source code. Any package
  metadata change causes a new Taskr build number, so the Debian revision stays
  fixed at `1`.
- 2026-08-07: Add `--install-deb` for local dogfooding. It should install the
  exact package produced by the current build, likely through `sudo apt install
  ./dist/<package>.deb`, but automated Smokey tests must not invoke sudo.

# Outcome

Implemented Debian package creation in `scripts/build.sh`:

- `scripts/build.sh deb` builds `dist/taskr_<version>-1_<arch>.deb`.
- `scripts/build.sh all` builds both `dist/taskr` and the Debian package from
  the same computed version.
- The package installs the binary as `/usr/bin/taskr`.
- Debian revision is fixed at `1`; package metadata changes are source changes
  and therefore produce a new Taskr build number.
- `scripts/build.sh deb --install-deb` installs the just-built package with
  `sudo apt install ./dist/<package>.deb`.

Pre-close checks:

- `bash -n scripts/build.sh` passes.
- `go test ./...` passes.
- `taskr --help` renders successfully.
- `taskr completion bash` renders successfully through Cobra's completion
  command.
- `smokey --tests-dir tests.d` passes, including `080-deb-package-workflow`.
- `--install-deb` is not executed by Smokey because it requires `sudo`; Michael
  verified the command path manually after the local-package path fix.
- No public API exists yet.
