# Description

Define the MVP feature scope for ticket types and identify subfeatures that
should be implemented separately.

# Acceptance

- The MVP feature scope states which commands expose ticket type first.
- The scope covers create-time type assignment, editing/changing type, listing,
  reporting, filtering, completion, and help/examples.
- The scope decides whether ticket type affects workflow, status transitions,
  prioritization, dependencies, or only reporting/filtering.
- The scope identifies doctor checks required for ticket type configuration and
  item metadata.
- The scope identifies Smokey coverage for the accepted MVP behavior.
- The scope lists follow-up subfeatures that should remain separate from the
  first implementation.
